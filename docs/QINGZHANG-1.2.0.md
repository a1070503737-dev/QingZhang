# 轻账 1.2.0 开发验收

基线为 `codex/qingzhang-1.1.0` 的 `d6ae943`。Kotlin、Compose、Hilt 和 Room 依赖沿用。版本为 1.2.0（versionCode 12）。仓库和 1.1.0 已签名 APK 使用 `com.zhuangxiu.ledger`，此次保留实际包名以支持覆盖安装。

## 账本与升级

- 新安装创建生活账本。账本页可新建普通或装修账本、改名、设置装修付款和照片功能、归档及恢复。首页和统计共用账本筛选。全部账本包含已归档账本的历史交易。
- Room 通过 1→2→3 迁移。第 3 版为旧订单增加 `bookId` 并关联至 ID 2 的装修账本。迁移保留全部订单 ID、分类 ID、付款状态、金额、付款、凭证关联及预算。旧付款方式标记为未指定，新付款可选与日常交易相同的支付方式。项目付款直接读取原表，避免复制产生重复支出。首次升级前保留 v1/v2 主库和 WAL 副本。
- 装修模板仍可使用项目、订金、尾款和凭证。普通及装修账本均可快速登记独立交易。收支页按照每笔实际付款的发生日期统计，项目总价和待付款仅在项目页面用于合同和付款计划。原装修预算沿用 ID 2 的范围。
- ZIP 继续包含数据库和照片。v3 备份包含账本、额外分类、交易和导入批次。v1 恢复迁移装修数据，并保留当前日常交易、账本设置、额外分类和导入记录。v2 或 v3 恢复按原有确认流程替换全部账本，原数据留在恢复前安全副本中。外部表格导入使用合并流程。

## 鲨鱼账单导入

公开记录显示两类表头和编码。MiniBill 的兼容测试记录了「日期、收支类型、类别、账户、金额、备注」和中文日期。FamilyFund 的导出分析记录了一个 UTF-16、Tab 分隔且没有账户列的版本。另一个公开 XLSX 导入实现记录了 Excel 序列日期。测试用自建脱敏数据复现这些结构。当前未收到用户自己的导出文件。

- [MiniBill 导入兼容测试](https://github.com/tianzongxinyu/miniBill/blob/fab5937d3cb555f2fe5440a4ed2760f874e02c02/internal/service/ledger_csv_flexible_test.go)
- [FamilyFund 导出格式记录](https://github.com/Haolun123/FamilyFund/blob/568e2c1fd858f9594b4c1dc288256cb62c7d72bf/docs/DESIGN_QUARTERLY_REPORT.md#86-鲨鱼记账-2026q1-数据分析)
- [公开 XLSX 导入实现](https://github.com/xli562/account_book/blob/1f9b9021100328f5af6857c74aa87cc11f1b55b8/modules/import_from_shark_excel.py)

设置 → 数据导入 → 从鲨鱼记账导入。通过系统文档选择器和 ContentResolver 读取。支持 UTF-8、有 BOM 的 UTF-8 和 UTF-16、GB18030/GBK、逗号/Tab/分号、引号及换行字段。XLSX 支持工作表选择、共享字符串、内联字符串及 1900/1904 Excel 日期。单次支持最多 50,000 笔和 16 MiB 原文件。旧式 XLS、公式及缺少完整年份的日期需要先转成明确的值。

表头、列和分类可在预览中调整。相同分类优先匹配，未知分类默认使用源名称创建，也可映射到现有分类。来源分类、账户和支付方式文本保留，缺失字段显示未指定。确认前列出无效记录和常见重复情况。

金额使用整数分。显式支出可使用正数或负数。正数退款方向计入收入，负数收入或退款列为疑义。缺少收支列时可明确选择按金额正负识别。转账、精度大于两位、无效金额或日期均提供失败原因。

在同一目标账本重复导入相同文件、表和列映射时，已导入的原行跳过。完全匹配的跨文件记录标为疑似重复，由用户决定是否跳过。相同文件里的两条相同明细按各自原行处理。用户确认后，在一个 Room 事务内创建账本或分类、记录批次并写入交易。提交前重新核对预览，变动时要求再次预览。结果显示成功、跳过、解析失败和逐月核对金额。

## 验收结果

离线运行 `./gradlew testDebugUnitTest assembleDebug assembleRelease lintDebug --offline` 成功。117 项测试通过，0 失败、0 跳过。Lint 为 0 错误、6 条警告和 1 条提示。

测试覆盖实际 v1/v2 schema 迁移、装修项目与分次付款、备份回读和恢复回滚、CSV/XLSX 变体、25,000 笔表格、非法记录、重复导入、导入后修改日期、事务回滚、逐月金额核对，以及文件选择、预览确认和首页刷新。环境未连接实体手机，尚未验证真机覆盖安装或用户自己的导出文件。

测试 APK 使用长期签名密钥。证书、包名和递增 versionCode 均已与 1.0.9 和 1.1.0 APK 比对。开发分支交付包含测试包，正式 Release 和更新清单保留现状。
