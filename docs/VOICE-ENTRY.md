# ai 记账

1. 在轻账首页点「ai 记账」。如有多个可用的日常账本，而且当前在全部账本或装修账本，先选要记入的日常账本。
2. 首次使用时授予麦克风权限。说「昨天早餐八元，午饭二十五元」，点「结束录音」。单次录音最长 45 秒。
3. 核对逐笔生成的草稿。可以改金额、日期、分类和备注，也可以修改识别出的文字再解析。确认后才保存到账本。检测到可能重复的账目时会再询问。
4. 麦克风不可用时，可以在同页直接输入文字。

## 模型与构建

轻账内置 Vosk 普通话小模型，语音以 16 kHz 单声道 PCM 在本机处理。第一次使用会把 APK 里的约 42 MB 模型解压到应用的私有目录。录音数据在内存中处理，转写后交给轻账内的规则生成草稿。出厂设置缺少系统中文识别服务的设备也能使用内置模型。

模型文件位于 app/src/main/assets/voice/vosk-model-small-cn-0.22.zip，原始归档的 SHA-256 为 3af8b0e7e0f835ae9d414ce5df580237a3cfb08d586c9fbbb0f7ff29ad5b14ba。归档按 Apache 2.0 许可分发，完整许可和来源在 APK 的 assets/voice 目录。

在真机上验证录音时，可安装调试 APK，在飞行模式下从首页开始录音，分别试普通话单笔、多笔及拒绝麦克风权限。调试包使用独立的应用数据。
