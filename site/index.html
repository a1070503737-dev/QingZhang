开始使用

三步安装，马上记账。

01

下载 APK

点击页面顶部「下载 Android APK」，从 GitHub 获取官方发布的安装包。

02

确认安装

在 Android 手机上打开 APK，按系统提示授权该下载来源并完成安装。

03

开始记录

直接创建账本记录收支。以后可在应用的「设置 → 检查更新」升级。

提示：卸载应用会删除本机账本数据。换机、重装或升级前请先导出备份，且不同签名的安装包不一定能直接覆盖安装。

常见问题

下载需要 GitHub 账号或者 Token 吗？

不需要。轻账的安装包通过公开的 GitHub Releases 下载，你可以直接获取 APK。

支持 iPhone 吗？

此页面提供的是 Android APK，无法直接安装在 iPhone 上。iOS 版本不在当前下载范围内。

记账必须联网吗？

日常记账使用本地存储，不需要登录。下载更新和使用 Google Drive 云备份需要网络。

在哪里核对安装包？

打开对应的 GitHub Release，查看 APK 与 SHA256SUMS 校验文件。下载后可用 SHA-256 对比文件完整性。
